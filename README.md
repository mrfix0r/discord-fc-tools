# FC Discord Tools

Две утилиты для Discord-сервера FC, сохранённые 04.09.2026.

| Папка | Назначение |
| --- | --- |
| `audit/` | Чтение структуры сервера и статистики активности |
| `migrator/` | Предпросмотр, применение и частичный откат плана перестройки |

Это инструменты для разового запуска через бот-аккаунт; постоянно держать
их работающими не требуется. Нужен Python 3.10+, сторонние пакеты не нужны.
Полные инструкции находятся в README каждой папки.

## Перед использованием мигратора

1. Скопируйте `migrator/migration_plan.example.json` в
   `migrator/migration_plan.json`.
2. Впишите ID сервера в `guild.expected_id`, проверьте имя сервера и сам план.
3. Передайте тот же ID через `-GuildId` при запуске `run_migration.ps1`.
4. Сначала проверьте предпросмотр. Применение требует отдельного `-Apply`
   и контрольной фразы, как и в исходной версии.

План отражает структуру FC от 04.09.2026. Это не запрос повторно применить
его к текущему серверу. Во время подготовки репозитория Discord не изменялся.

## Что исключено

Токены, ID рабочего сервера, локальный заполненный план, отчёты аудита,
резервные копии и журналы. Шаблон сохраняет названия каналов и ролей FC.

## Офлайн-проверки

Из корня репозитория:

```sh
python -m unittest discover -s migrator/tests -v
python -m unittest discover -s audit -p 'test_*.py' -v
```

Исходные архивы: `discord-fc-migrator(1).zip`, `discord-readonly-audit.zip`.
Для GitHub заменён серверный ID, добавлена локальная копия конфигурации и
уточнены команды запуска. В тесте аудита исправлен путь к соседнему модулю.
Ограничения на операции мигратора сохранены.
